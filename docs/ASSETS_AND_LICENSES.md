# Assets and licences

All content currently in the project is **original** and generated by code or
authored as data in this repository. No third-party meshes, textures, HDRIs,
fonts or sounds are included.

| Asset | Source | Licence |
|---|---|---|
| Vehicle bodies, wheels, interiors (procedural) | `scripts/world/procedural/*` | Project (original) |
| Engine assemblies and bay dressing (procedural) | `scripts/world/procedural/*` | Project (original) |
| Workshop geometry and props | `scripts/world/garage_builder.gd`, `workshop_props.gd` | Project (original) |
| Surface textures (concrete, paint flake, tread, leather, carbon weave, oil stains) | Generated at runtime with `FastNoiseLite` | Project (original) |
| Sky for ambient light / reflections | `ProceduralSkyMaterial` | Project (original) |
| UI font | Godot default font | Godot engine (MIT) |

## Recording a new asset

Add a row with: file path in the project, original URL, author, licence (with
version, e.g. CC-BY 4.0), date obtained, and what was changed. Keep the original
licence text next to the asset if it requires attribution.
